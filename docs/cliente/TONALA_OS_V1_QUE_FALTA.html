Tonala OS

Qué falta para la versión utilizable (V1)
Para: Cliente / equipo territorial · 14 de agosto de 2026 · Objetivo: V1 utilizable

En una frase: Hoy Tonala OS tiene el motor (contactos, territorio, asignaciones y visitas en base de datos) pero falta la aplicación web completa que el equipo use cada día sin ayuda técnica.

1. Qué ya está hecho

  • Registrar contactos con nombre
  • Vincular contacto a colonia (territorio)
  • Asignar responsable a un contacto
  • Programar y completar visitas (con reglas de negocio)
  • Base de datos, permisos en servidor, historial de cambios
  • Pruebas automáticas del núcleo (143 pruebas pasando)

Esta base no se tira; se reutiliza.

5. Qué falta — Equipo (campo)

  • Mi día — visitas de hoy para el responsable
  • Mis visitas y mis contactos asignados
  • Completar visita desde el teléfono

6. Operación sin botones de técnico

  • Procesar eventos automáticamente tras cada acción
  • Quitar botones de “preparar base de datos” de la interfaz
  • Ambiente de pruebas (staging) antes de producción

Decisiones ya acordadas

  1. Mapa — Todos los usuarios lo ven y lo usan.
  2. Capturista — Puede dejar responsable pendiente; color distinto al asignado.
  3. Mapa V1 — Lo más completo y fluido posible.
  4. Al entrar — Cada rol ve la pantalla que más le ayuda.

Orden de trabajo

Paso 1 → Login + aplicación web
Paso 2 → CRM completo
Paso 3 → Mi día y visitas en campo
Paso 4 → Mapa de Tonala completo
